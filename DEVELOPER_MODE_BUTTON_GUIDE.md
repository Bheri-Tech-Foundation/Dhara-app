## 📍 Where to Find It:

### On Web/Desktop:

1. **Login to the dashboard**
2. Look at the **top-right corner**
3. You'll see (from left to right):
   - Your profile picture
   - Your name
   - **🔧 Developer Mode Icon** ← **NEW BUTTON!**
   - ⋮ Menu icon

---

## 🎨 Button Appearance:

- **Icon**: 🔧 (developer_mode icon)
- **When Developer Mode is OFF**: Gray color
- **When Developer Mode is ON**: Green/Primary color (highlighted)
- **Tooltip**: Hover to see "Developer Settings"

---

## 🔐 How to Use:

### Step 1: Click the Developer Mode Button
- Click the 🔧 icon in the top-right

### Step 2: Enter Password
- A password dialog will appear
- Default password: **`dev123`**
- Click "Unlock"

### Step 3: Configure Settings
- Developer Settings modal opens
- Toggle Developer Mode ON
- Enter your backend URL (e.g., `http://localhost:8000`)
- Click "Apply Custom URL"

### Step 4: Verify
- The 🔧 button will turn **green/highlighted**
- This indicates Developer Mode is active
- All APIs now use your custom backend!
